زما د کوډونو ټولګه 💻

دلته زما غوره کوډونه، پروژې او نمونې وګورئ

د HTML ساده پاڼه

دا د یو ساده HTML کوډ نمونه ده چې تاسو یې کولی شئ په خپل ویب سایټ کې وکاروئ.

<!DOCTYPE html>
<html>
<head>
    <title>زما پاڼه</title>
</head>
<body>
    <h1>ښه راغلاست!</h1>
</body>
</html>

د CSS رنګونه

د CSS په مرسته د ویب سایټ ښکلا او رنګونه څنګه تنظیم کړو.

body {
    background-color: #0f172a;
    color: white;
    font-family: Arial;
}

د JavaScript فنکشن

دا یو ساده JavaScript فنکشن دی چې د کاروونکي سره مرسته کوي.

function greet(name) {
    alert("سلام " + name + "!");
}
greet("احمد");
